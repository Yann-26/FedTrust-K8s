# FedTrust-K8s: Reproducibility Guide

## Quick Start

### Prerequisites
- Docker (>=20.10)
- Docker Compose (>=2.0) or `docker compose` plugin
- 8GB RAM minimum (16GB recommended)
- 10GB free disk space

### One-Command Setup

```bash
git clone https://github.com/Yann-26/FedTrust-K8s.git
cd FedTrust-K8s
chmod +x scripts/*.sh
./scripts/setup.sh
